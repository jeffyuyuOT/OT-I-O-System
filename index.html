使用者管理

管理可以登入這個 App 的帳號。每個帳號有一個主要身分(管理者/訂貨用戶/倉庫管理員),新增帳號時會依身分帶入預設可看的分頁,之後仍可針對個別帳號再細部勾選調整可看的分頁。

尚無使用者
新增使用者帳號

為了安全,建立新的登入帳號要在 Supabase 後台操作(密碼會由 Supabase 妥善加密儲存,而不是存在這個網頁裡):
1. 到 Supabase 專案的 Authentication → Users → Add user
2. Email 填 帳號名稱@inventory.local(例如 tom@inventory.local)
3. 密碼自行設定,再告訴那位同事
4. 展開 User Metadata,貼上例如 {"username": "tom", "role": "order"}(role 可填 admin / order / inventory)
5. 存檔後,這個帳號就會自動出現在上面的清單,可再細部調整他能看到哪些分頁。

分頁排序

調整上方分頁列(系統管理、庫存管理…等)顯示的先後順序。

會計 Email

進貨單勾選「寄送給會計」時,預設帶入的收件人地址(送出前還是可以改成別的地址)。可以加多個地址,標記「主要」的那個會放在收件人(To),其他的會放在副本(CC)一起寄出。

Stock Location
格式

決定「庫存分布」頁面新增/編輯位置時,要怎麼填位置資訊。標準模式強制照 Zone-Aisle-Bay-Level-Bin 分開填寫(例如 A03-12-02-1);自訂模式可以自己輸入整串位置文字。

標準模式底下實際要用到哪幾個欄位(不是每個倉庫都需要用滿 5 個)。

列印

勾選後,Picking Slip 最前面會多印一欄「Stock Location」。如果商品有多個位置,列印之前會先跳出視窗問要從哪個位置拿取、印出那個位置。

Multipack 商品設定

只有主商品「剛好只有一種 multipack 商品」,或已經在編輯商品畫面勾選「顯示於總庫存量」指定某個 multipack 商品時才會生效;數量不足整數倍的部分,仍會用主商品下單。

訂單核對設定

勾選後,「登記進出貨 → 出貨 → 載入現有待處理訂單」下面的「直接核對」選項會隱藏,只能用「載入訂單核對頁面」的方式核對(需要先比對實際點貨內容才能確認)。

商品排序

決定庫存總覽(沒有手動點欄位排序時)、訂貨頁面裡,同一個分類底下的商品要怎麼排序。分類本身的先後順序另外在庫存總覽用「調整分類順序」設定。

勾選後,訂貨頁面 multipack 商品名稱前面的「⧉」圖示不顯示,商品名稱直接往前對齊,跟其他一般商品的名稱起始位置一致。

已完成訂單匯出格式

決定已完成訂單匯出 Excel 時,商品清單要怎麼列。

從 Excel 匯入商品主檔

偵測到你之前上傳的 stock.xlsx,裡面有 66 項商品(品名、單位、庫存量、平均使用量、分類、安全庫存)。按下方按鈕匯入:新商品會新增,已存在的商品會自動比對並更新庫存量/分類/平均值/安全庫存/備註(庫存量不同會產生一筆調整紀錄),不會重複新增。

商品主檔匯入產生的初始庫存/庫存調整紀錄,預設不會顯示在「進出貨紀錄」分頁裡,但仍會計入庫存量。你手動登記或用「登記進出貨→從 Excel 匯入」的進出貨都會照常顯示。

上傳你自己的商品主檔 Excel

可以一次選取多個檔案。第一列要是欄位標題,系統會自動辨識這些欄位名稱(大小寫、中英文都可以):
必要:SKU、Name/品名、Stock/庫存量  |  選填:Unit/單位、AvgMonthlySales/平均使用量、Categories/分類、SafetyStock/安全庫存(填月數,不是填數量)、Note/備註
以 SKU 為比對主鍵:表格裡的 SKU 如果跟現有商品相同,就算表格上的名稱不一樣,也會視為同一項商品並更新其他欄位;商品名稱一律維持庫存總覽現有的名稱,不會被表格覆蓋。SKU 不同或全新的 SKU 會用表格上的名稱新增成一項新商品。沒有填 SKU 的資料列會被略過,不會寫入。

掃描收據數據庫

管理收據掃描的記憶對照表。預設列出所有跟商品相關的記憶(不含被記成「略過,不是商品資訊」的那些),可以往下滑瀏覽,也可以用分類篩選或選特定商品縮小範圍;勾選「包含略過的資訊」才會連那些一起列出來。如果之前不小心對到錯的商品,可以在這裡刪除,下次掃描到同樣文字就會重新跳出來問。

進貨預估

目前庫存可撐是跟庫存總覽一樣的算法(用平均出貨量推算);填了「預計進貨數量」之後,右邊「進貨後庫存可撐」會即時算出把這批貨加進去、大概還能再撐多久(用(預計進貨數量+目前庫存量)除以平均用量估算),方便抓進貨量的參考,不會真的異動庫存。

匯出報表

選擇「類型」(出貨/進貨/入庫),依「對象」跟日期區間篩選紀錄,匯出成 Excel 報表(格式比照 stock_out_sheet 範本,含 SKU、分類等欄位)。同一對象、同一商品在選取區間內會自動加總成一筆,不會重複列出每一次的紀錄。

從 Excel 匯入進出貨紀錄
